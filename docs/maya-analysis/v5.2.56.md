# Maya v5.2.56 — kya naya hai, TARGET me kya kami hai, aur build plan

Source: `maya-v5.2.56-83c8be8dee6f.apk` (package `com.getmaya.android`, versionName 5.2.56, versionCode 245, minSdk 26, targetSdk 34). Manifest androguard se decode kiya, dono dex (12,902 classes, 62,896 strings) ki strings nikali, assets/native libs dekhe. Code R8 se obfuscated hai, isliye features strings, tool names, endpoints aur asset names se pehchane gaye.

TARGET ko `main` @ `a6dcdd4` (2026-11-09) se compare kiya: web (`src/`, Next.js 14 + Supabase) aur app (`target-app/`, Kotlin + Compose).

> Sirf reference. Maya ka code, prompts, voices, models, images ya brand assets TARGET me copy nahi karne. Decompiled files repo me nahi hain.
>
> **Caveat:** 5.2.52 ka APK/strings dump available nahi tha, isliye "naya" ka matlab hai "pichhle docs (`structured.md`, `tools.md`, `decompile.md`) me nahi tha". Kuch cheezein 5.2.52 me bhi ho sakti hain jo tab miss hui.

Legend: ✅ TARGET me hai · 🟡 thoda hai · ⬜ nahi hai · (A) = web workstream · (B) = Android workstream

## 1. 5.2.52 → 5.2.56: kya badla

### Size aur packaging
- APK 31.8 MB → **41.5 MB**. versionCode 241 → 245.
- **Permissions bilkul same** (47, ek bhi add/remove nahi).
- `armeabi-v7a` me ab sirf basic libs hain (barcode, tflite, aec3); `onnxruntime`, `pockettts`, `hunterstt`, `turndetector` sirf **arm64**. Matlab purane 32-bit phones pe wake word + on-device models band ("on this phone off" wala message).

### Naye components (manifest)
| Component | Kya lagta hai |
|---|---|
| `ui.terminal.TerminalReelActivity` + `termux.live.TerminalStopReceiver` + tool `terminal_record` | Termux session ko live dikhana / record karke reel jaisa video banana |
| `core.AssistantNudgeReceiver` | "Maya ko default assistant banao" nudge — card ya notification se, dismiss count track hota hai |
| `com.google.android.gms.common.api.GoogleApiActivity` | Play-services Google Sign-In (Drive scope `drive.file`) |
| `voice.barge.Aec3Native` (`libmaya_aec3.so`) | WebRTC AEC3 echo canceller — bolte waqt user beech me bole (barge-in) |

### Voice stack me naya
- **Echo cancellation for barge-in**: WebRTC AEC3 native lib + **DTLN-aec** tflite models (`assets/dtln/`, ~7 MB). Logs: `BARGE aec3 …`, `barge_route`, canceller fallback. Matlab TTS chalte hue bhi mic sunta hai aur apni hi awaaz ko cancel karta hai.
- **Wake word models APK me bundled**: `assets/wakeword/` — melspectrogram + embedding + teen phrase classifiers ("hey", "hello", "wake up" + naam). openWakeWord jaisa 3-stage design (~5 MB). Battery-saver me wake word band karne ka alag setting.
- **Deepgram streaming STT** (`wss://api.deepgram.com/v1/listen`, nova-3) — "Maya Soul / conversation mode" ke liye user ki apni key; Google recognizer fail ho to honest message.
- **Ultra voices** (server se mp3 previews) aur "Hunter TTS Ultra Premium" — paid, skip.

### "Advanced Agentic Mode" (sabse bada naya hissa)
- Normal mode = Gemini Live (speech-to-speech). Agentic mode = **cascade**: on-device/Deepgram STT ("Kaan") → tool-calling LLM ("brain", user ka OpenAI-compatible URL/model/key ya server plan) → TTS ("awaaz").
- Har failure ka alag, saaf message aur **automatic fallback to normal mode**: server busy, server down, version mismatch, licence nahi, key galat, model tool-calling nahi karta, phone ki date galat, limit khatam… User ko kabhi "error" nahi, hamesha "abhi normal mode chal raha hai, ye khud dobara try karega".
- Agentic rules (`AgenticRules`) alag versioned bundle me aate hain.
- Plan/credits/limits wala hissa (`/v1/agentic/plan*`, toolbaaz.online) — **TARGET ke liye exclude** (payments).

### Naye backend endpoints (app ↔ apna server)
`/api/android/bootstrap`, `/api/android/config`, `/api/android/heartbeat`, `/api/android/notices`, `/api/android/tools` (server se tool catalog), `/api/android/sites`, `/api/android/avatar/`, `/api/android/referral`, `/api/v1/lease`, `/api/v1/ingest`, `/v1/ticket`. (Licence/checkout/referral wale paid hisse skip.)

### Naye external providers
xAI Grok (image), Deepgram (STT), Gemini `v1beta/interactions`, Google PageSpeed (website review), OpenClaw local gateway (`localhost:18789`), Hermes agent repo (Termux recipe).

### Behaviour patterns jo naye dikhe (apne shabdon me)

## 4. Build plan — do alag workstreams

Dono streams ek **shared contract** pe chalein (neeche §4.0). Contract pehle merge ho (docs-only), phir A aur B parallel. App aur website same Supabase user, same `/api/chat`, same conversations.

### 4.0 Shared contract (pehle likhna, dono taraf test)
**Poora exact contract: [`docs/app-api.md`](../app-api.md) (v1, protocol = 1).** Wahi source of truth hai; neeche short summary. Types: `src/lib/device/protocol.ts` + `src/lib/device/tools.ts` (A) aur `target-app/.../net/DeviceProtocol.kt` (B).

- **Auth**: har native request `Authorization: Bearer <supabase access_token>` + `X-Target-Client: android/<versionCode>`. Bearer header cookie se pehle check hota hai; cookie path fallback rahe. Token refresh: `POST /api/app/session/refresh {refresh_token}` → `{access_token, refresh_token, expires_at}` (ya WebView reload). `/admin` kabhi bearer nahi leta.
- **Capabilities**: app `/api/chat` body me `client: {kind:"android", version, versionCode, capabilities:["call","sms","whatsapp","screen.read","screen.tap",...], locale}` bheje. Capability strings ki list `docs/app-api.md` §5 me.
- **Stream framing** (naya, exact): `/api/chat` abhi bhi `text/plain` stream hai. Event = ek line jo ASCII Record Separator `\u001e` se shuru ho aur `\n` pe khatam, beech me compact JSON. Server event se pehle hamesha `\n` likhta hai aur model text se `\u001e` hata deta hai. Events chat history me save nahi hote, web ko kabhi nahi milte.
- **Device tool call** (server → app): `\u001e{"type":"device_call","id":"dc_…","tool":"device.make_call","args":{…},"risky":true,"say":"Mummy ko call karun?","timeoutMs":30000,"conversationId":"…"}`. Model ko naam `device__make_call` dikhta hai (OpenAI tool names me `.` allowed nahi); event me `device.make_call`.
- **Result** (app → server): `POST /api/app/device-results {conversationId, id, ok, result|error, code?, verified:boolean}` → `200 {status:"accepted"|"late"}`, `409 already_answered`, `404`. Agent loop isi request me wait karta hai (30 s) aur result milte hi aage chalta hai. Late results next `/api/chat` turn me `deviceResults[]` se bhi bhej sakte ho.
- **Timeout** 30 s; result na aaye to server `\u001e{"type":"device_timeout","id":"dc_…"}` bhejta hai aur model honest "phone se jawab nahi aaya" bolta hai.
- **Errors**: non-2xx JSON `{error, kind}`; `kind` ∈ `auth|rate|busy|down|version|bad_request|not_found|server` (A14) taaki app sahi line bole.
- Risky tools phone pe hi confirm hote hain (existing `brain/Confirm.kt` + "bina pooche" toggles) — server kabhi bypass nahi kar sakta.
- App endpoints: `GET /api/app/bootstrap`, `POST /api/app/heartbeat`, `GET /api/app/notices`, `GET /api/app/tools` — shapes `docs/app-api.md` §4 me.
