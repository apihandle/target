TARGET worker. Add the Space secret SESSION_WORKER_SECRET (same value as on Vercel).

Smart browser jobs with the same abilities as the built-in cloud worker: one-time codes (Gmail or the code form in chat), emailed verify / reset links (Gmail), saved site sessions, and checkouts / bookings that stop before the final button. Code and video jobs need the compute worker (docs/COMPUTE-WORKER.md).
